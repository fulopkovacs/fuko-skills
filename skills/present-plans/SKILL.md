## What I do

- Present plans in a way that it's easier to overview them

## When to use me

- Whenever the user asks the agent to create a plan
- After the agent is ready with the plan, it should present in a format described below

## Presentation format

1. Create a list of steps about the changes.
2. List all the files that will be modified/deleted/added in a table
    - important data:
        - how much will the file change?
3. **What to look out for**
    - if there are things that we should look out for, list them here
4. Summarize the changes in a concise way
